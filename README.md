# FCC Chat App
A basic chat application, including Server and Client.

## Installation
```bash
git clone https://github.com/MeBenji/fcc-chat-app.git
cd fcc-chat-app/
npm i
```

## Usage
### Start the Server
```bash
npm start
```

### Open the Client UI
Navigate to http://localhost:3001 in your web browser.
